# By endpoint

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/api/v1/catalog` | Каталог сайтов, доступных для парсинга: поиск по названию, описанию и домену. |
| `POST` | `/api/v1/categories` | Запускает сбор категорий сайта. Если список уже есть в кэше, сразу возвращается `completed` без повторного сбора. |
| `GET` | `/api/v1/categories/:id` | Статус и результат сбора категорий. |
| `GET` | `/api/v1/credentials` | Список сохранённых логинов для сайтов, где нужна авторизация. Пароли не возвращаются. |
| `POST` | `/api/v1/credentials` | Добавляет логин и пароль. Если такая пара уже есть, пароль обновляется, `id` остаётся прежним. |
| `POST` | `/api/v1/export` | Запускает выгрузку товаров парсинга в выбранный формат. |
| `GET` | `/api/v1/export/:id` | Статус выгрузки: очередь, прогресс, файлы или ссылки результата. |
| `GET` | `/api/v1/format` | Список форматов выгрузки: идентификаторы, названия и схема опций. |
| `GET` | `/api/v1/me` | Текущий пользователь: тариф, баланс и AI Points. |
| `POST` | `/api/v1/parser` | Запускает парсинг товаров. Полноценный парсинг платного сайта — только с действующим тарифом. Пробный парсинг — с `trial: true`, доступен без тарифа. Если `categories` не передан или пустой, список категорий будет загружен автоматически |
| `GET` | `/api/v1/parser/:id` | Статус парсинга: очередь, прогресс, ошибка. |
| `GET` | `/api/v1/parser/:id/goods` | Список товаров парсинга с постраничной выдачей. |
| `POST` | `/api/v1/parser/:id/resume` | Возобновляет вручную остановленный парсинг — то же, что кнопка «Возобновить». Парсинг должен быть в статусе `canceled` и не в архиве. Успешно завершенный, завершенный с ошибкой, еще идущий или архивный парсинг возобновить нельзя: |
| `POST` | `/api/v1/parser/:id/stop` | Останавливает незавершенный парсинг — то же, что кнопка «Остановить» в интерфейсе. Парсинг в очереди или в работе переходит в статус `canceled`. Уже завершенный или уже остановленный парсинг остановить нельзя: ответ `unprocessable`. |
| `GET` | `/api/v1/parser/list` | История парсингов. |
| `GET` | `/api/v1/website/:domain` | Схема настроек парсера для сайта: нужна ли авторизация, ручные категории и какие опции передавать при запуске. |
