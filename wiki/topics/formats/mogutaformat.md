# Как выгрузить товары в Moguta?

**Category:** `cms` · **Target:** Moguta
**Source:** https://q-parser.ru/howto/format/mogutaformat

Список товаров на Moguta выгружается в формате CSV. Файл уже подготовлен для импорта на платформу Moguta в соответствии с [инструкцией на сайте разработчика](http://wiki.moguta.ru/tovary/import-praysa-iz-csv).

### 1. В списке товаров нажмите "Выгрузить"

После загрузки товаров на парсер, находясь на странице со списком товаров, нажмите кнопку "Выгрузить".

![Как выгрузить товары в Moguta - Шаг 1](/static/howto/export-1.png)

### 2. Задайте настройки формата

В появившемся окне выберите формат "Moguta (moguta.ru)", задайте необходимые настройки и сформируйте файл для импорта товаров.

Обратите внимание, что импорт фото по ссылкам поддерживает только одно фото на товар.

### 3. Загрузите файл в Moguta

В панели управления вашего магазина Moguta перейдите в раздел **Товары** и нажмите **Загрузить из CSV/Excel**.

Выберите файл для загрузки. Затем укажите соответствие стобцов в файле.

![Как выгрузить товары в Moguta - Шаг 3](/_app/immutable/assets/export-moguta-2.rx3cy7-w.png)

![Как выгрузить товары в Moguta - Шаг 3](/_app/immutable/assets/export-moguta-3.DsuSm0ou.png)

### 4. Дождитесь окончания импорта

После запуска дождитесь окончания импорта товаров.

![Как выгрузить товары в Moguta - Шаг 4](/_app/immutable/assets/export-moguta-4.CPAEA7Wt.png)

## Настройки формата

**Многострочные характеристики** — если установлено в "Запрещено", то все пропуски строк в характеристиках (например, в описании)
будут заменены на пробелы.

## Специальные характеристики

Часть колонок заполняется значением характеристики с фиксированным названием. Если у товара такой характеристики нет, колонка
останется пустой. Эти характеристики не дублируются в остальных характеристиках.

**Вес** — характеристика «Вес».

Название должно совпадать точно. Переименовать характеристику можно в [редактировании товаров](/howto/mods/cols-rename).
