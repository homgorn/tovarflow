# Как выгрузить товары в OpenCart?

**Category:** `cms` · **Target:** OpenCart
**Source:** https://q-parser.ru/howto/format/opencartexportimportformat

Выгрузка товаров производится в формате OpenCart для модуля [Export/Import](https://www.opencart.com/index.php?route=marketplace/extension/info&extension_id=17).

## Сортировка товаров

В связи с особенностью формата импорта, товары должны идти в строгом порядке, поэтому сортировка товаров силами Q-Parser не будет
работать при выгрузке в этот формат.

## Описание набора формируемых файлов

Для OpenCart Export/Import Tool формируются несколько отдельных файлов, каждый из которых предназначен для своей цели. Импортировать
файлы рекомендуется в порядке, перечисленном ниже.

Если файл отсутствует в выгрузке, значит он не содержит никаких полезных данных.

**attributes.xlsx** — файл содержит набор атрибутов каталога. Это характеристики, которые пользователь может увидеть у товара
и их не нужно выбирать при покупке. Используются при фильтрации каталога.

**options.xlsx** — файл содержит набор опций каталога. Это характеристики товаров, которые необходимо выбрать перед заказом.
Например размеры, цвета и пр.

**categories.xlsx** — набор категорий и подкатегорий каталога.

**products.xlsx** — основной список товаров. Также содержит все атрибуты и опции товаров.

**images.zip** — архив с изображениями для товаров. Необходимо загрузить содержимое архива (распаковав его перед загрузкой) в
вашу папку с картинками OpenCart (обычно "image").

## Импорт без атрибутов и опций

Если по каким-либо причинам вы не хотите импортировать атрибуты и опции товаров, то для этого:

- Не импортируйте файлы **attributes.xlsx** и **options.xlsx**;
- В файле **products.xlsx** вручную удалите следующие листы: ProductOptions, ProductOptionValues, ProductAttributes;

## Настройки формата

**Поместить в поле model** — выберите значение, которое будет помещено в поле **model** файла импорта.

**Поместить в поле sku** — выберите значение, которое будет помещено в поле **sku** файла импорта.

**ID категорий** — способ формирования ID категорий в файле. Недавно он изменился, поэтому категории, импортированные
раньше, при повторном импорте могут создаться заново. Чтобы сохранить прежние ID, на ограниченное время можно выбрать **Старый метод**.

## Специальные характеристики

Часть колонок заполняется значением характеристики с фиксированным названием. Если у товара такой характеристики нет, колонка
останется пустой.

**manufacturer** — характеристика «Бренд».

Название должно совпадать точно. Переименовать характеристику можно в [редактировании товаров](/howto/mods/cols-rename).
