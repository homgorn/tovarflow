# Как выгрузить товары в каталоги Facebook* (CSV)?

**Category:** `social` · **Target:** каталоги Facebook* (CSV)
**Source:** https://q-parser.ru/howto/format/facebookcsvformat

Выгрузка формирует CSV-файл (UTF-8, разделитель — запятая) для загрузки товаров в [каталоги Facebook\*](https://www.facebook.com/business/help/890714097648074). Загрузка производится в [Catalog Manager](https://www.facebook.com/products/),
требования к полям файла описаны в [документации](https://www.facebook.com/business/help/120325381656392).

Это CSV-вариант фида [Facebook\* (XML)](/howto/format/facebookxmlfeedformat): вариации у обоих форматов выгружаются
одинаково. В CSV дополнительно выгружаются штрихкод (**gtin**), вес (**shipping\_weight**) и HTML-описание (**rich\_text\_description**).

### 1. В списке товаров нажмите "Выгрузить"

После загрузки товаров на парсер, находясь на странице со списком товаров, нажмите кнопку "Выгрузить".

![Как выгрузить товары в каталоги Facebook* (CSV) - Шаг 1](/static/howto/export-1.png)

### 2. Задайте настройки формата

В появившемся окне выберите формат "Facebook\* - Catalog Manager (CSV)", задайте необходимые настройки и сформируйте файл для импорта
товаров.

### 3. Откройте Catalog Manager и выберите каталог

Скачайте файл к себе на компьютер, затем откройте [Catalog Manager](https://www.facebook.com/products/) и выберите (или создайте) ваш каталог с товарами. Выгрузка производится только для каталогов вида **"Электронная коммерция"**.

В левом меню выберите "Источники данных о товарах", затем справа "Добавить товары".

![Как выгрузить товары в каталоги Facebook* (CSV) - Шаг 3](/_app/immutable/assets/export-facebookxmlfeedformat-1.ClZDeaFT.png)

### 4. Загрузите файл

В появившемся окне выберите "Использовать массовую загрузку".

![Как выгрузить товары в каталоги Facebook* (CSV) - Шаг 4](/_app/immutable/assets/export-facebookxmlfeedformat-2.BBA6-t6K.png)

Затем выберите "Загрузка файла" и загрузите CSV-файл. Файл сразу пройдет валидацию, убедитесь, что не появляется сообщений об
ошибке. Запустите импорт товаров и дождитесь результатов импорта.

![Как выгрузить товары в каталоги Facebook* (CSV) - Шаг 4](/_app/immutable/assets/export-facebookxmlfeedformat-3.SwS3ndv7.png)

![Как выгрузить товары в каталоги Facebook* (CSV) - Шаг 4](/_app/immutable/assets/export-facebookxmlfeedformat-4.CrEq-Iwb.png)

Чтобы каталог обновлялся автоматически, в том же окне можно выбрать "Обновление фида по графику" и указать ссылку на файл, доступный
в интернете.

## Вариации

Если у товара есть характеристики с несколькими значениями (например, несколько цветов или размеров), для каждой комбинации значений
выгружается отдельная строка-вариация с общим **item\_group\_id** — артикулом товара. Цена, остаток, фото и описание у всех
вариаций одинаковые. Цвет, размер, пол, материал и узор попадают в стандартные колонки Facebook\*, остальные характеристики с
несколькими значениями — в **additional\_variant\_attribute** в виде `Рост:170,Длина:Макси`. Товар без таких
характеристик выгружается одной строкой без **item\_group\_id**.

## Артикул товара

Колонка **id** заполняется артикулом товара, у вариации к нему через дефис дописываются значения характеристик. Если артикула
нет, используется код, построенный по ссылке на товар. Такой код не меняется между выгрузками, но если ссылка на товар изменится,
Facebook\* примет его за новый товар. Чтобы этого избежать, задайте артикулы в [редактировании товаров](/howto/mods).

## Особенности формата

- **description** — описание простым текстом (не длиннее 9999 символов). Если в описании есть HTML, исходное
  HTML-описание дополнительно выгружается в **rich\_text\_description**. Товар без описания получает текст "Нет описания товара".
- **price** и **sale\_price** — если старая цена выше текущей, в **price** попадает старая цена, а в **sale\_price** — текущая. Цена выгружается с кодом валюты, например `1350 RUB`.
- **availability** — если наличие товара неизвестно, он выгружается как "в наличии" (`in stock`).
- **quantity\_to\_sell\_on\_facebook** — остаток товара. Если остаток неизвестен, колонка пустая, у отсутствующего товара —
  0.
- **product\_type** — полный путь категории через " > ".
- **image\_link** — первое фото, **additional\_image\_link** — следующие фото, не больше 20.
- Для товара Facebook\* требует бренд. Если бренда нет, заполните характеристику «Штрихкод» (**gtin**) или «MPN» (**mpn**).

\* Meta признана экстремистской организацией в России.

## Специальные характеристики

Часть колонок заполняется значением характеристики с фиксированным названием. Если у товара такой характеристики нет, колонка
останется пустой. Своих колонок для остальных характеристик у Facebook\* нет, поэтому все характеристики товара добавляются к
описанию **description**.

**color** — характеристика «Цвет».

**size** — характеристика «Размер».

**gender** — характеристика «Пол»: значения «Женский», «Мужской», «Унисекс»; нераспознанное значение не выгружается.

**material** — характеристика «Материал».

**pattern** — характеристика «Узор».

**gtin** — характеристика «Штрихкод»: только 8, 12, 13 или 14 цифр.

**shipping\_weight** — характеристика «Вес»: значение выгружается как есть. Facebook\* ждет число с единицей измерения через
пробел, например `0.5 kg` или `500 g`. Значение без единицы может быть не принято: допишите ее в [редактировании товаров](/howto/mods).

**mpn** — характеристика «MPN»: код производителя. Артикул в эту колонку не выгружается.

Название должно совпадать точно. Переименовать характеристику можно в [редактировании товаров](/howto/mods/cols-rename).
