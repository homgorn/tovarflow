# Как выгрузить товары в ReadyScript?

**Category:** `cms` · **Target:** ReadyScript
**Source:** https://q-parser.ru/howto/format/readyscriptformat

[ReadyScript](https://readyscript.ru/) — CMS для интернет-магазинов. Выгрузка
делается для стандартного импорта CSV ([документация ReadyScript](https://readyscript.ru/manual/catalog_csv_import_export.html)): пять CSV-файлов с разделителем «;», которые импортируются по очереди в разных разделах админки.

В выгрузке пять файлов, номер в названии — порядок импорта:

- **--1-categories.csv** — категории всех уровней;
- **--2-properties.csv** — характеристики;
- **--3-property-values.csv** — значения характеристик;
- **--4-products.csv** — товары;
- **--5-offers.csv** — комплектации товаров.

### 1. В списке товаров нажмите "Выгрузить"

После загрузки товаров на парсер, находясь на странице со списком товаров, нажмите кнопку "Выгрузить".

![Как выгрузить товары в ReadyScript - Шаг 1](/static/howto/export-1.png)

### 2. Задайте настройки формата

В появившемся окне выберите формат "ReadyScript (readyscript.ru)", задайте необходимые настройки и сформируйте файлы для импорта
товаров. Скачайте все файлы выгрузки (или ZIP-архив с ними и распакуйте его).

### 3. Подготовьте ReadyScript

**Кодировка.** Кодировка файлов должна совпадать с настройкой CSV в ReadyScript: **Веб-сайт → Настройка модулей → Системный модуль**, вкладка «CSV импорт/экспорт». По умолчанию там Windows-1251, как и
в выгрузке.

**Старая цена.** Старая цена выгружается в колонку «Цена\_Зачеркнутая цена». Чтобы она загрузилась, создайте в разделе **Товары → Справочник цен** тип цен «Зачеркнутая цена» (задаваемый вручную) и выберите его в настройках модуля каталога в поле
«Старая(зачеркнутая) цена». Без такого типа цен колонка не сопоставится.

### 4. Импортируйте категории

Перейдите в **Товары → Каталог товаров**, нажмите **Импорт/Экспорт** в правом верхнем углу и выберите **Импорт категорий из CSV**. Выберите файл **--1-categories.csv** и нажмите «Загрузить файл».

![Как выгрузить товары в ReadyScript - Шаг 4](/_app/immutable/assets/readyscript-1.HK_6z764.jpg)

Откроется окно сопоставления колонок: колонки с совпадающими названиями сопоставляются автоматически. Проверьте их и нажмите «Начать
импорт». Так же проверяйте сопоставление при импорте каждого следующего файла.

![Как выгрузить товары в ReadyScript - Шаг 4](/_app/immutable/assets/readyscript-2.COVqzOSw.jpg)

### 5. Импортируйте характеристики

Перейдите в **Товары → Характеристики**, нажмите **Импорт/Экспорт** и выберите **Импорт характеристик из CSV**.
Загрузите файл **--2-properties.csv**. Характеристики нужно импортировать до товаров, иначе многомерные комплектации не
создадутся.

![Как выгрузить товары в ReadyScript - Шаг 5](/_app/immutable/assets/readyscript-3.D2K6CRp_.jpg)

![Как выгрузить товары в ReadyScript - Шаг 5](/_app/immutable/assets/readyscript-4.BU7j1wa4.jpg)

### 6. Импортируйте значения характеристик

В том же разделе **Товары → Характеристики** выберите **Импорт/Экспорт → Импорт значений характеристик из CSV** и
загрузите файл **--3-property-values.csv**.

![Как выгрузить товары в ReadyScript - Шаг 6](/_app/immutable/assets/readyscript-5.Dgc6B6kB.jpg)

### 7. Импортируйте товары

Вернитесь в **Товары → Каталог товаров**, выберите **Импорт/Экспорт → Импорт товаров из CSV** (не «Расширенный
импорт») и загрузите файл **--4-products.csv**.

![Как выгрузить товары в ReadyScript - Шаг 7](/_app/immutable/assets/readyscript-6.jejuv-O0.jpg)

### 8. Импортируйте комплектации

Там же выберите **Импорт/Экспорт → Импорт комплектаций из CSV** и загрузите файл **--5-offers.csv**. Если у товаров нет
опций, файл комплектаций пустой и этот шаг можно пропустить.

![Как выгрузить товары в ReadyScript - Шаг 8](/_app/immutable/assets/readyscript-7.B0QkErJS.jpg)

## Особенности формата

**Комплектации.** Характеристики с несколькими значениями («Размер», «Цвет» и т.п.) становятся многомерными комплектациями: на сайте
покупатель выбирает значение по каждой опции. В файле комплектаций строка на каждое сочетание значений, цена и остаток у всех комплектаций
как у товара.

Комплектации связаны с товаром по названию. В настройках модуля каталога поле «Поле идентификации товара во время импорта CSV
комплектаций» должно указывать на короткое название товара (так по умолчанию). Если у разных товаров одинаковые названия,
комплектации попадут в первый найденный товар.

**Остатки.** Остаток товара выгружается в колонку «Доступно», остаток комплектаций — в колонку «Остаток по складу "Основной склад"».
В старых версиях ReadyScript или если склад называется иначе, сопоставьте эти колонки вручную. При включенном складском учете ReadyScript
не принимает остатки из CSV.

Если на сайте-доноре нет остатков, колонки остатков пустые и ReadyScript запишет 0. Товары без наличия выгружаются с остатком 0.
Учтите это, если в настройках каталога включено «Скрывать товары с нулевым остатком».

**Характеристики** создаются без группы. Если в магазине уже есть одноименная характеристика в группе, будет создана новая, без группы.
Видео и файлы товара выгружаются в характеристики «Видео» и «Файлы».

**Повторный импорт.** ReadyScript ищет товар по короткому названию и артикулу: найденные товары обновляются, при несовпадении названия
или артикула создается новый товар.

## Характеристики

Характеристики с несколькими значениями становятся многомерными комплектациями.
