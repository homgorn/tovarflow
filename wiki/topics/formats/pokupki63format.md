# Как выгрузить товары на 63pokupki.ru?

**Category:** `sp` · **Target:** 63pokupki.ru
**Source:** https://q-parser.ru/howto/format/pokupki63format

[63pokupki.ru](https://63pokupki.ru/) — сайт совместных покупок в Самаре. Выгрузка формирует
CSV-файл с разделителем ";": по строке на товар, размеры и фото в одной ячейке через ";".

### 1. В списке товаров нажмите "Выгрузить"

После загрузки товаров на парсер, находясь на странице со списком товаров, нажмите кнопку "Выгрузить".

![Как выгрузить товары на 63pokupki.ru - Шаг 1](/static/howto/export-1.png)

### 2. Задайте настройки формата

В появившемся окне выберите формат "63покупки (63pokupki.ru)", задайте необходимые настройки и сформируйте файл для импорта товаров.

### 3. Загрузите файл на 63pokupki.ru

Загрузите файл в кабинете организатора на 63pokupki.ru.

## Особенности формата

**Колонки** — "категория" (полный путь категории через " > "), "бренд", "каталог" (всегда пустая), "название", "цена", "артикул",
"количество на складе", "старая цена", "описание", "размер", затем колонки характеристик, последней — "фото".

**Характеристики** — остальные характеристики, включая "Видео", выгружаются отдельными колонками с тем же названием, несколько
значений — через ";". Характеристика, название которой без учета регистра совпадает с колонкой формата ("Артикул", "Бренд", "Фото"
и т.п.), не выгружается.

## Специальные характеристики

Часть колонок заполняется значением характеристики с фиксированным названием. Если у товара такой характеристики нет, колонка
останется пустой.

**размер** — характеристика «Размер», несколько значений через ";".

Название должно совпадать точно. Переименовать характеристику можно в [редактировании товаров](/howto/mods/cols-rename).
