# Как выгрузить товары в 1С-Битрикс (Bitrix)?

**Category:** `cms` · **Target:** 1С-Битрикс (Bitrix)
**Source:** https://q-parser.ru/howto/format/bitrixcsvformat

Список товаров для 1С-Битрикс выгружается в формате CSV.

Поддерживается выгрузка только простых товаров, торговые предложения не поддерживаются. Выбираемые характеристики выгружаются в виде
дополнительных свойств.

### 1. В списке товаров нажмите "Выгрузить"

После загрузки товаров на парсер, находясь на странице со списком товаров, нажмите кнопку "Выгрузить".

![Как выгрузить товары в 1С-Битрикс - Шаг 1](/static/howto/export-1.png)

### 2. Задайте настройки формата

В появившемся окне выберите формат "Битрикс (CSV)", задайте необходимые настройки и сформируйте файл для импорта товаров.

### 3. Настройте интернет-магазин для импорта

Если вы не уверены в настройках своего магазина, обратитесь в поддержку своего сайта. Сайты на 1С Битрикс могут работать очень по
разному. Q-Parser не несет ответственность за настройки вашего сайта.

В панели управления 1С-Битрикс перейдите в **Настройки -> Настройки продукта -> Настройки модулей -> Торговый каталог -> вкладка Экспорт/Импорт**.

Выберите доступные поля для товара: Внешний код, Название, Детальная картинка, Детальное описание, Тип детального описания, Вес,
Производитель и другие поля.

Для групп выберите поле "Название".

Каждый уровень категории выгружается в отдельную колонку: IC\_GROUP0, IC\_GROUP1, IC\_GROUP2 и т.д. Битрикс импортирует столько уровней
групп, сколько задано в настройках модуля (по умолчанию 3). Если у категорий на сайте-доноре больше уровней, увеличьте количество
уровней групп в этих настройках, иначе товары попадут в группу 3-го уровня.

Для простых товаров также необходимо выбрать поля для цены (Цена, Валюта) и доступные валюты.

### 4. Настройте каталог

Перейдите в **Контент -> Инфоблоки -> Типы инфоблоков -> Каталоги -> ваш инфоблок**

На вкладке **Поля**:

- Включите опцию "Создавать картинку анонса из детальной"
- Выберите тип детального описания html или text в зависимости от наличия HTML-тегов в описании
- Включите опцию "Транслитерировать из названия при добавлении элемента"
- Выключите опцию "Использовать внешний сервис для перевода"

На вкладке **Свойства**:

- Для параметров с множественными значениями (размер, цвет и т.д.) установите опцию "Множ."
- Добавьте характеристики из прайса, которые еще не созданы

### 5. Добавьте профиль импорта

Перейдите в **Магазин -> Настройки -> Импорт данных -> Добавить профиль (Import CSV)**

Задайте настройки:

- Разделитель полей: точка с запятой
- Первая строка содержит имена полей
- Использовать настройки инфоблока для обработки изображений
- Использовать настройки инфоблока для транслитерации

### 6. Выполните импорт

Загрузите файл с товарами и запустите импорт.

## Специальные характеристики

Часть колонок заполняется значением характеристики с фиксированным названием. Если у товара такой характеристики нет, колонка
останется пустой. Эти характеристики не дублируются в отдельных колонках: туда попадают остальные.

**BRAND** — характеристика «Бренд».

**CP\_WEIGHT** — характеристика «Вес».

**CP\_LENGTH** — характеристика «Длина».

**CP\_WIDTH** — характеристика «Ширина».

**CP\_HEIGHT** — характеристика «Высота».

Название должно совпадать точно. Переименовать характеристику можно в [редактировании товаров](/howto/mods/cols-rename).
