# Как выгрузить товары в Joomla (Excel2JS)?

**Category:** `cms` · **Target:** Joomla (Excel2JS)
**Source:** https://q-parser.ru/howto/format/joomlaformat

Выгрузка предназначена для интернет-магазинов на Joomla с JoomShopping, где установлен платный компонент импорта [Excel2JS](https://joom-shopping.com/products/excel2js). Подробно компонент описан в [документации разработчика](https://joom-shopping.com/Excel2js-doc).

Файл выгружается в формате Excel (XLSX), одна строка на товар. Это не формат Comiel для встроенного импорта JoomShopping: для него
есть [отдельный формат](/howto/format/joomshoppingformat).

### 1. В списке товаров нажмите "Выгрузить"

После загрузки товаров на парсер, находясь на странице со списком товаров, нажмите кнопку "Выгрузить".

![Как выгрузить товары в Joomla (Excel2JS) - Шаг 1](/static/howto/export-1.png)

### 2. Задайте настройки формата

В появившемся окне выберите формат "Joomla: Excel2JS (JoomShopping)", задайте необходимые настройки и сформируйте файл для импорта
товаров.

### 3. Создайте зависимый атрибут «Размер»

Если у товаров есть размеры, в панели управления JoomShopping перейдите в **Опции > Атрибуты** и создайте зависимый атрибут «Размер».
Значения атрибута заводить не нужно: Excel2JS добавит их сам при импорте.

![Как выгрузить товары в Joomla (Excel2JS) - Шаг 3](/_app/immutable/assets/joomla-1.DX3TNuA1.jpg)

### 4. Настройте профиль Excel2JS

Откройте **Компоненты > Импорт/Экспорт товаров JoomShopping > Профили настроек**. Excel2JS сопоставляет колонки файла с
полями по номерам, поэтому перетащите из неактивных столбцов в активные поля в том же порядке, что и колонки в файле:

![Как выгрузить товары в Joomla (Excel2JS) - Шаг 4](/_app/immutable/assets/joomla-2.CBs1RRXF.jpg)

1. Код товара
2. ID товара (колонка пустая, ее можно не активировать)
3. Категория (Номер/ID/Название)
4. Наименование товара
5. Краткое описание
6. Полное описание
7. Цена
8. Изображение
9. Вес
10. Производитель
11. Количество
12. Валюта
13. Список характеристик
14. Размер (оранжевое поле зависимого атрибута)
15. Количество (Зависимый атр.)

Оранжевые поля — зависимые атрибуты. Не забудьте поле "Количество (Зависимый атр.)": по нему задаются остатки размеров. На
скриншоте ниже пример профиля с другим набором полей.

![Как выгрузить товары в Joomla (Excel2JS) - Шаг 4](/_app/immutable/assets/joomla-3.1-iJKb0c.jpg)

В основных настройках профиля укажите разделитель уровней вложенности категорий **>** и разделитель изображений **|**.
Способ идентификации товаров выберите по коду товара: колонка "ID товара" в файле пустая.

![Как выгрузить товары в Joomla (Excel2JS) - Шаг 4](/_app/immutable/assets/joomla-4.B4DAKSpW.jpg)

### 5. Запустите импорт

Откройте **Компоненты > Импорт/Экспорт товаров JoomShopping > Импорт**, выберите настроенный профиль, укажите выгруженный
файл и нажмите "Начать импорт".

![Как выгрузить товары в Joomla (Excel2JS) - Шаг 5](/_app/immutable/assets/joomla-5.BQUW43qT.jpg)

## Особенности формата

Набор и порядок колонок фиксированы, иначе они не совпадут с профилем Excel2JS.

Категория выгружается полным путем, уровни разделены символом **>**.

Изображения выгружаются ссылками через **|**.

Колонка "ID товара" остается пустой: ID товара на сайте-источнике не подходит для вашего магазина. Колонка "Количество" пустая, если
остаток неизвестен: тогда Excel2JS подставит количество по умолчанию из профиля.

Характеристики выгружаются в колонку "Список характеристик" строкой вида `Имя:Значение|Имя:Значение`, несколько значений
одной характеристики — через запятую. Старая цена, ссылки на видео и файлы тоже попадают в этот список. Если в настройке
"Выгрузка характеристик" выбрать "Добавить к описанию", характеристики будут дописаны к описанию товара.

HTML-разметка в описании сохраняется. Цены выгружаются с десятичной точкой.

## Специальные характеристики

Часть колонок заполняется значением характеристики с фиксированным названием. Если у товара такой характеристики нет, колонка
останется пустой. Эти характеристики не дублируются в колонке **Список характеристик**: туда попадают остальные.

**Размер** — характеристика «Размер»: зависимый атрибут, несколько размеров записываются через **|**. Остаток каждого
размера в колонке "Количество(Зависимый атр.)" равен остатку товара.

**Вес** — характеристика «Вес».

Название должно совпадать точно. Переименовать характеристику можно в [редактировании товаров](/howto/mods/cols-rename).
