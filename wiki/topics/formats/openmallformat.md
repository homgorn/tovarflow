# Как выгрузить товары на OpenMall?

**Category:** `cms` · **Target:** OpenMall
**Source:** https://q-parser.ru/howto/format/openmallformat

[OpenMall](https://openmall.info/) — платформа интернет-магазинов и дропшиппинга.
Выгрузка формирует CSV-файл с разделителем ";" для массовой загрузки товаров. Колонки файла при импорте сопоставляются с полями
OpenMall вручную. Официальная инструкция — [массовое добавление товаров](https://blog.openmall.info/faq/massovoe-dobavlenie-tovarov/).

### 1. В списке товаров нажмите "Выгрузить"

После загрузки товаров на парсер, находясь на странице со списком товаров, нажмите кнопку "Выгрузить".

![Как выгрузить товары на OpenMall - Шаг 1](/static/howto/export-1.png)

### 2. Задайте настройки формата

В появившемся окне выберите формат "OpenMall (openmall.info)", задайте необходимые настройки и сформируйте файл для импорта товаров.

### 3. Откройте импорт товаров

В панели управления admin.openmall.info перейдите в раздел **Каталог → Товары** и нажмите **Перейти к товарам**.

![Как выгрузить товары на OpenMall - Шаг 3](/_app/immutable/assets/openmall-1.C5kEaEA5.png)

В списке товаров справа вверху нажмите **Импортировать товары**.

![Как выгрузить товары на OpenMall - Шаг 3](/_app/immutable/assets/openmall-2.DVHdtxdU.png)

### 4. Загрузите файл и сопоставьте колонки

Выберите разделитель ";", нажмите **Загрузить .csv .xls или .xlsx** и выберите файл. Затем укажите колонки для каждого поля:

- **Название категории** — CATEGORY;
- **ID категории** — CATEGORY\_IDS (по желанию);
- **ID товара** — ID;
- **Артикул товара** — ARTICLE;
- **Название товара** — TITLE;
- **Описание товара** — DESCRIPTION;
- **Фотографии** — IMAGES;
- **Цена товара** — PRICE, рядом выберите валюту цены;
- **Вариации** — колонки опций ("Размер", "Цвет" и т.д.), каждую добавьте кнопкой "+";
- **Ссылка на товар** — URL.

Нажмите **Подтвердить загрузку**.

![Как выгрузить товары на OpenMall - Шаг 4](/_app/immutable/assets/openmall-3.CLpnW775.png)

### 5. Добавьте категории в магазин

После загрузки перейдите в раздел **Мои магазины → Категории** и нажмите **Добавить все категории поставщика**. Категории
из файла появятся в магазине вместе с товарами.

![Как выгрузить товары на OpenMall - Шаг 5](/_app/immutable/assets/openmall-4.CphN9wtO.png)

## Особенности формата

**Характеристики в описании** — отдельных полей для характеристик в импорте OpenMall нет, поэтому характеристики (кроме опций)
добавляются в описание товара строками "Название: значение". Туда же попадают бренд, старая цена, остаток, краткое описание, видео и файлы.

**Категория** — полный путь категории, уровни через запятую.

**ID товара** — число, вычисленное из артикула и ссылки на товар: OpenMall принимает в ID только цифры. Сам артикул выгружается
в колонку ARTICLE.

**Фото** — ссылки через запятую, первое фото становится основным. Цена выгружается с точкой в качестве десятичного разделителя.

## Характеристики

Характеристики с несколькими значениями становятся опциями товара: каждая выгружается отдельной колонкой с тем же названием,
значения через запятую. Запятая внутри значения заменяется: в числах на точку ("42,5" → "42.5"), в остальных случаях на " / ".
