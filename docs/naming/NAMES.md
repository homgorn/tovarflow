# Domain name shortlist — 2026-11-27

Project: catalogue ingestion (Q-Parser) → canonical catalogue → storefronts and marketplace/WordPress channels.

Brief: RU-first, Russian-speaking owner, Latin base that reads as a Russian word or an unambiguous
combination, no `ж щ ч ш й х ц` in the assumed Russian reading, no digits/hyphens, SEO-bearing roots
`tovar`, `katalog`, `vitrina`, `sync`, `feed`, `port`, `kit`. Zones checked first: `.ru`, then `.com`
for finalists. `.ru` is the starting zone per the domain skill; `.com` is for global expansion.

## Caveats

- WHOIS status is a point-in-time observation, not proof of a clean history.
- Wayback and exact quoted searches in Yandex/Google are recorded separately for candidates that
  pass WHOIS. Absence of traces is not proof that a domain was never registered.
- Registration price and registrar availability are not checked here.
