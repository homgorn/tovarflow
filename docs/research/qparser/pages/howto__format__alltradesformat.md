[AllTrades](https://alltrades.ru/) — платформа для создания интернет-магазинов. Выгрузка
формирует CSV-файл с разделителем ";" для штатного импорта товаров из CSV. Все товары выгружаются одним файлом, сгруппированными по разделам.

### 1. В списке товаров нажмите "Выгрузить"

После загрузки товаров на парсер, находясь на странице со списком товаров, нажмите кнопку "Выгрузить".

![Как выгрузить товары на AllTrades - Шаг 1](/static/howto/export-1.png)

### 2. Задайте настройки формата

В появившемся окне выберите формат "AllTrades (alltrades.ru)", задайте необходимые настройки и сформируйте файл для импорта товаров.

### 3. Загрузите файл в AllTrades

В панели управления магазина откройте раздел **Мой магазин → Импорт/Экспорт → Импорт товаров из CSV** и загрузите файл.

## Особенности формата

**Разделы** — перед товарами каждой категории в файле стоит строка "Раздел" с ее названием, и все товары ниже относятся к этому
разделу. Название раздела — полный путь категории через " > " (например, "Одежда > Платья"). После импорта разделы можно переименовать
или переложить в нужную вложенность.

**Количество** — остаток товара. Если товара нет в наличии, выгружается 0, если остаток неизвестен — 100.

**Описание** — краткое и полное описание выгружаются в свои колонки.

**Производитель** — бренд товара.

**Старая цена** — старая цена товара.

**URL изображений (через запятую)** — ссылки на фото через запятую.

**Характеристики** — каждая характеристика, в том числе "Размер", "Цвет", "Видео" и "Файлы", выгружается отдельной колонкой с
тем же названием. Несколько значений пишутся в одну ячейку, каждое с новой строки. Если название характеристики совпадает с колонкой формата
("Тип", "Артикул", "URL" и т.п.), ее колонка получит название "<название> (характеристика)".

## Специальные характеристики

Часть колонок заполняется значением характеристики с фиксированным названием. Если у товара такой характеристики нет, колонка
останется пустой. Эти характеристики не дублируются отдельными колонками.

**Страна-производитель** — характеристика «Страна-производитель».

**Вес, кг** — характеристика «Вес».

Название должно совпадать точно. Переименовать характеристику можно в [редактировании товаров](/howto/mods/cols-rename).
