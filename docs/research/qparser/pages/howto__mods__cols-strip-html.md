Если характеристики парсятся с html-тегами, но вам они не нужны, можно убрать все html-теги с автоматическим форматированием
пропуска строк.

В меню редактирования товаров выберите "Характеристики — Убрать HTML-теги". Выберите характеристику или укажите "Все".

Можно задать условия, чтобы внести изменения только в части товаров.

Некоторые форматы выгрузки убирают все html-теги автоматически.

![Убрать HTML-теги](/_app/immutable/assets/mods-strip-html.kaqJk4nB.png)

### Пример

Допустим, у товара есть характеристика "Описание" с HTML-тегами:

```
<p>Этот товар имеет:</p>
<ul>
    <li>Высокое качество</li>
    <li>Надежную сборку</li>
</ul>
<p><b>Гарантия 12 месяцев</b></p>
```

После применения модификатора "Убрать HTML-теги", текст будет преобразован в:

```
Этот товар имеет:

Высокое качество
Надежную сборку

Гарантия 12 месяцев
```

**Важно:** Система автоматически заменяет некоторые HTML-элементы на соответствующие символы форматирования, тем не менее без html
не удастся сохранить форматирование текста.
