### Доступные форматы выгрузки

После парсинга товаров Q-Parser позволяет выгрузить данные в различных форматах: скачать файл для загрузки на сайт или выгрузить
напрямую в социальные сети через API.

### Универсальные файловые форматы

**CSV/Excel (XLS)** — универсальный формат для импорта в большинство CMS и интернет-магазинов. [Инструкция по CSV](/howto/format/csvformat), [Инструкция по Excel](/howto/format/xlsformat)

**XML** — структурированный формат для интеграции с различными системами. [Инструкция по XML](/howto/format/xmlformat)

**YML** — специализированный формат от Яндекс.Маркета, подходящий для огромного числа CMS и интернет-магазинов. [Инструкция по YML](/howto/format/ymlformat)

### Специализированные форматы CMS

Готовые форматы для популярных CMS и платформ: OpenCart, PrestaShop, Shopify, 1C-Битрикс, Tilda, InSales, Moguta, OkayCMS и других.
Каждый формат уже настроен под требования конкретной CMS — не нужно настраивать соответствие полей.

### Прямая выгрузка в социальные сети

Автоматическая загрузка товаров через API без необходимости скачивать файлы.

- [ВКонтакте — Товары](/howto/format/vkformat)
- [ВКонтакте — Альбомы](/howto/format/vkalbumsformat)
- [Одноклассники — Товары](/howto/format/okformat)
- [Одноклассники — Альбомы](/howto/format/okalbumsformat)

### Форматы для совместных покупок

Специализированные форматы для платформ СП: SuperPuper, StOSP, Pokupki-Prosto, LP Motor, Serpok и другие.

## Предложить новый формат выгрузки

Если вам требуется дополнительный формат выгрузки товаров, которого нет в списке выше, пожалуйста, оставьте заявку через чат или
почту и укажите следующие данные (по возможности):

- Сайт или платформу, на которую будет загружаться файл;
- Описание формата файла: тип (CSV, XML, JSON и др.), кодировку и другие особенности;
- Подробное описание полей файла: обязательные и опциональные поля, разделители, формат дат, работа с изображениями;
- Особые требования: ограничения по размеру, специфические правила валидации, формат загрузки.

Если есть возможность, пришлите пример готового файла в нужном формате. Это значительно ускорит процесс добавления нового формата на
платформу.

Мы регулярно добавляем новые форматы выгрузки на основе запросов пользователей. Популярные форматы добавляются в приоритетном
порядке.
