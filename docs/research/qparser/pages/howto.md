Q-Parser предлагает несколько способов выгрузки товаров. Вы можете выбрать наиболее удобный вам:

- Выбрать сайт поставщика из [нашего каталога](/catalog);
- С помощью [виджета](/supplier/widget) на сайте поставщика;
- С помощью [кнопки на панели закладок](/howto/button) в браузере;

Любой из перечисленных способов позволяет в несколько кликов выгрузить нужный вам сайт.
