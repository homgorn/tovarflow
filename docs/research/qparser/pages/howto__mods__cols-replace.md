Q-Parser позволяет перед выгрузкой товаров произвести поиск и замену произвольного текста в характеристиках товаров. Это дает
возможность убрать ненужный текст или заменить одни значения другими.

## Поиск и замена текста в характеристиках

В меню редактирования товаров выберите "Характеристики — Поиск и замена". В появившемся окне необходимо:

- Выбрать характеристику в которой производить поиск;
- Ввести текст для поиска;
- Ввести текст на который его нужно заменить (можно оставить пустым);

Можно задать условия, чтобы внести изменения только в части товаров.

При поиске во "всех" характеристиках, замены в ссылках на фото не производятся.

**Обратите внимание!** Текст будет заменен без учета регистра символов, т.е. РАЗМЕР и размер - будет считаться одинаковым текстом при
поиске.

![Поиск и замена по товарам](/_app/immutable/assets/mods-search-replace.BOC4YQxl.png)

### Искомая строка

Искомая строка может быть любой, но если она содержит символы `%`, то они будут считаться шаблоном. Например, если
искомая строка `%артикул%`, то вместо этого в поиск будет подставлен артикул каждого товара.

Если требуется выполнить поиск по выражению, похожему на шаблон, но не являющемуся шаблоном, используйте поиск по регулярному
выражению.

### Заменяемое значение

Текст, на который требуется заменить искомую строку может быть любым, либо быть пустым (в этом случае строка будет удалена).

Также возможно использовать шаблоны как в [редактировании характеристик](/howto/mods/cols). Например, если в заменяемом
значении указать `%артикул%`, то все найденные значения будут заменены на артикул текущего товара.

## Поиск по регулярным выражениям

Наиболее удобным и продвинутым способом поиска и замены являются регулярные выражения. Для их включения необходимо установить
соответствующую галочку под полем ввода текста.

Модификаторы указаны справа от поля ввода (пример: /exp+/uisg) и их нельзя изменить. Поддерживается захват групп и замена по
индексам захваченных групп.

![Поиск и замена по регулярным выражениям](/_app/immutable/assets/mods-search-regex.DpiPW-dN.png)

## Изменение ссылок изображений

С помощью поиска и замены можно модифицировать ссылки на фото. Для этого выберите поиск в характеристике "Изображения".

При редактировании ссылок на фото вы можете все сломать, если ссылки в итоге окажутся недействительными.

Нельзя отредактировать ссылки, получаемые посредством модификации фото.
