JSON — универсальный формат для разработчиков: его удобно читать из своих скриптов и программ. Готового импорта на какой-либо
площадке у него нет, структуру файлов описываем ниже.

Файлы выгружаются в кодировке UTF-8.

### 1. В списке товаров нажмите "Выгрузить"

После загрузки товаров на парсер, находясь на странице со списком товаров, нажмите кнопку "Выгрузить".

![Как выгрузить товары в JSON - Шаг 1](/static/howto/export-1.png)

### 2. Задайте настройки формата

В появившемся окне выберите формат "JSON", задайте необходимые настройки и сформируйте файлы.

### 3. Скачайте файлы

По окончании выгрузки появятся ссылки на два файла:

- **…--categories.json** — дерево категорий;
- **…--products.json** — товары.

При настройке "Разбить на несколько файлов" товары делятся на файлы **…--products--<группа>.json**, а файл категорий
остается один общий для всех групп. Файл категорий выгружается всегда, даже если у товаров нет категорий (тогда в нем пустой
массив).

## Структура файлов

Каждый файл — JSON-массив объектов.

### Категории

В файле категорий — все уровни категорий товаров выгрузки без повторов. Родительская категория всегда идет раньше вложенных.

- **id** — ID категории (число);
- **parent\_id** — ID родительской категории, `null` у категорий верхнего уровня;
- **name** — название категории;
- **level** — уровень вложенности, 1 — верхний уровень;
- **path** — полный путь от верхнего уровня через `>`.

ID категории вычисляется из домена сайта и пути категории, поэтому он не меняется между выгрузками одного сайта. Одноименные
подкатегории в разных разделах получают разные ID.

```
[
{
  "id": 2104361044,
  "parent_id": null,
  "name": "Одежда",
  "level": 1,
  "path": "Одежда"
},
{
  "id": 394652197,
  "parent_id": 2104361044,
  "name": "Футболки",
  "level": 2,
  "path": "Одежда > Футболки"
}
]
```

### Товары

У каждого товара есть все ключи, порядок ключей всегда одинаковый.

- **article** — артикул;
- **title** — название;
- **url** — ссылка на товар на сайте-источнике;
- **price** — цена (число);
- **old\_price** — старая цена (число);
- **currency** — валюта;
- **quantity** — остаток (целое число);
- **publish** — наличие (`true`/`false`);
- **brand** — бренд;
- **category\_id** — ID категории товара (самого глубокого уровня) из файла категорий;
- **category** — полный путь категории через `>`, совпадает с **path** в файле категорий;
- **images** — ссылки на изображения;
- **images\_files** — имена файлов изображений в ZIP-архиве, если выбрана выгрузка изображений в ZIP;
- **short\_description** — краткое описание;
- **description** — описание;
- **video\_links** — ссылки на видео;
- **file\_links** — ссылки на файлы;
- **data** — характеристики товара.

Если значения нет, у цены, старой цены, остатка, наличия и **category\_id** стоит `null`, у строк — пустая строка `""`, у списков — пустой массив `[]`.

Своего ID у товара нет. Если он нужен, сформируйте его сами, например из **url** и **article**.

```
[
{
  "article": "art-1",
  "title": "Футболка",
  "url": "https://site.ru/good-1",
  "price": 99.5,
  "old_price": 150,
  "currency": "RUB",
  "quantity": 1,
  "publish": true,
  "brand": "Бренд",
  "category_id": 394652197,
  "category": "Одежда > Футболки",
  "images": ["https://site.ru/img/1-1.jpg", "https://site.ru/img/1-2.jpg"],
  "images_files": [],
  "short_description": "Краткое описание",
  "description": "<p>Описание товара</p>",
  "video_links": [],
  "file_links": [],
  "data": [
    {"name": "Размер", "values": ["S", "M"]},
    {"name": "Материал", "value": "Хлопок"}
  ]
}
]
```

## Характеристики

Стандартные поля товара выгружаются отдельными ключами, а все характеристики идут в массив **data** с исходными названиями и в исходном
порядке.

Характеристика с одним значением записывается как `name` + `value` (строка или число), с несколькими
значениями (например, размеры) — как `name` + `values` (массив строк). Пустые характеристики в файл не попадают.
