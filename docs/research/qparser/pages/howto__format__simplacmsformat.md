Список товаров для Simpla CMS выгружается в формате CSV. Файл уже подготовлен для импорта на платформу Simpla CMS, дополнительных
манипуляций не требуется.

### 1. В списке товаров нажмите "Выгрузить"

После загрузки товаров на парсер, находясь на странице со списком товаров, нажмите кнопку "Выгрузить".

![Как выгрузить товары в Simpla CMS - Шаг 1](/static/howto/export-1.png)

### 2. Задайте настройки формата

В появившемся окне выберите формат "Simpla CMS", задайте необходимые настройки и сформируйте файл для импорта товаров.

### 3. Импортируйте файл в свой магазин

Зайдите в панель управление сайтов и импортируйте полученный файл в свой магазин, следуя инструкциям в панели управления.
