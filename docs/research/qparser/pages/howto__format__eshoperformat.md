Список товаров на Eshoper выгружается в формате Excel (XLSx). Файл уже подготовлен для импорта на платформу Eshoper, дополнительных
манипуляций не требуется.

Eshoper рекомендует импортировать за один раз не более 20 000 товаров.

### 1. В списке товаров нажмите "Выгрузить"

После загрузки товаров на парсер, находясь на странице со списком товаров, нажмите кнопку "Выгрузить".

![Как выгрузить товары в Eshoper - Шаг 1](/static/howto/export-1.png)

### 2. Задайте настройки формата

В появившемся окне выберите формат "Eshoper (eshoper.ru)", задайте необходимые настройки и сформируйте файл для импорта товаров.

### 3. Перейдите в раздел Импорт из Excel

В панели управления вашего магазина Eshoper перейдите в раздел **Импорт из Excel**.

Задайте необходимые настройки обновления товаров, выберите файл с товарами и запустите импорт.

![Как выгрузить товары в Eshoper - Шаг 3](/_app/immutable/assets/export-eshoper-2.CBNNrJU0.png)

![Как выгрузить товары в Eshoper - Шаг 3](/_app/immutable/assets/export-eshoper-3.BjuaOV9A.png)

### 4. Дождитесь окончания импорта

После запуска дождитесь окончания импорта товаров и импорта изображений (это происходит отдельно). По завершению импорта появится
отчет о загруженных товарах.

![Как выгрузить товары в Eshoper - Шаг 4](/_app/immutable/assets/export-eshoper-4.BPTcyPI7.png)

## Категории

Eshoper поддерживает до 5 уровней категорий: колонки «Категория» и «Подкатегория 1»–«Подкатегория 4». Если уровней больше,
оставшиеся объединяются в колонке «Подкатегория 4» через «>».

## Специальные характеристики

Часть колонок заполняется значением характеристики с фиксированным названием. Если у товара такой характеристики нет, колонка
останется пустой. Эти характеристики не дублируются в дополнительных характеристиках и параметрах: туда попадают остальные.

**Производитель** — характеристика «Бренд».

**Вес, кг** — характеристика «Вес».

**Ширина, см** — характеристика «Ширина».

**Высота, см** — характеристика «Высота».

**Длина, см** — характеристика «Длина».

Название должно совпадать точно. Переименовать характеристику можно в [редактировании товаров](/howto/mods/cols-rename).
