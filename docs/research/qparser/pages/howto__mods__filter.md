Q-Parser позволяет отфильтровать товары перед выгрузкой. Фильтры применяются ко всему парсингу, последовательно один за другим. Все
фильтры работают как логическое "И", т.е. чтобы товар попал в выгрузку, необходимо, чтобы он прошел все фильтры.

## Общая информация

Для добавления фильтра товаров в меню редактирования товаров выберите "Добавить фильтр". В появившемся окне необходимо указать
характеристику товаров, тип фильтрации и запрос для фильтрации.

**Обратите внимание**, что фильтрация товаров осуществляется без учета изменений, внесенных на вкладке Редактирование. Удобнее
сначала настроить фильтры и только потом редактировать товары.

Максимальное число фильтров в одном парсинге: 1000, включая фильтры удаления товаров.

Максимальная длина поля, по которому возможна фильтрация: 30 000 символов.

![Фильтрация товаров](/_app/immutable/assets/filter-button.WUGxvd5D.jpg)

## Удаление товаров

Вы можете быстро исключить конкретный товар, щелкнув на иконку удаления возле товара. В этом случае создается фильтр НЕ на ссылку
товара, позволяя исключить его из выгрузки.

![Удаление товаров](/_app/immutable/assets/goods-remove-btn.BcZtscO9.png)

## Типы фильтрации

![Типы фильтрации](/_app/immutable/assets/filter-types.D4IuO6Q7.png)

### Точное соответствие

Выбирает товары, выбранное поле которых точно соответствует заданному запросу. Регистр символов не учитывается.

Нажмите на "Добавить запрос" чтобы добавить фильтрацию по нескольким значениям одновременно (через ИЛИ).

### Вхождение

Выбирает товары, выбранное поле которых содержит указанный запрос. Например, запрос "красный" выберет товары со значением "красный
берет".

В запросе можно использовать символ звездочки (\*) для соответствия любому набору символов. Или символ вопроса (?) для соответствия
одному символу.

Например, запрос "красн\*е" будет соответствать товарам "красные", "красное", "краснодарское" и т.п.

Нажмите на "Добавить запрос" чтобы добавить фильтрацию по нескольким значениям одновременно (через ИЛИ).

### Существует

Выбирает только те товары, у которых существует указанная характеристика.

### НЕ-фильтр

Установите галочку если требуется заставляет фильтр работать наоборот, т.е. соответствовать не-заданному запросу.

### Числовые фильры

Фильтры вида "Больше или равно (>=)" выбирают товары, которые соответствуют заданным параметрам. Такие фильтры доступны для цены,
изображений и других числовых характеристик.
