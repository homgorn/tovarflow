Q-Parser позволяет сделать определенный цвет на фотографиях товаров прозрачным. Это полезно для удаления однотонного фона с
изображений или создания фотографий на прозрачном фоне для последующего размещения на своем фоне.

Можно задать условия, чтобы внести изменения только в части товаров.

### Как сделать цвет прозрачным?

В меню редактирования товаров выберите "Фото — Сделать прозрачным".

В появившемся окне можно выбрать:

- **Цвет** — цвет, который нужно сделать прозрачным. Выберите цвет с помощью палитры или укажите точный HEX-код, нажав на него.
- **Допуск** — диапазон похожих оттенков (0-255). Значение 0 удалит только точно совпадающие пиксели, большие значения удалят и похожие
  оттенки. По умолчанию: 5.

![Сделать цвет прозрачным](/_app/immutable/assets/mods-images-transparent.Bx5gTipo.png)

### Как работает допуск?

Допуск определяет, насколько похожим должен быть цвет пикселя на выбранный, чтобы стать прозрачным. Это особенно полезно для
удаления фона с небольшими вариациями цвета из-за теней, освещения или сжатия изображения.

- **Допуск 0** — станут прозрачными только пиксели с точно таким же цветом
- **Допуск 5-20** — подходит для удаления однотонного фона с небольшими вариациями
- **Допуск 50+** — удалит широкий диапазон похожих оттенков

### Важные особенности

**Формат изображения автоматически изменится на PNG.** Это необходимо, так как только формат PNG поддерживает прозрачность. Формат
JPG не поддерживает прозрачные области.

Если вам нужно удалить белый фон, выберите белый цвет (#ffffff) и установите допуск 10-20 для удаления не только чисто белого, но и
слегка сероватых пикселей, которые могут остаться из-за сжатия фотографии.

### Рекомендации

- Начните с небольшого значения допуска (5-10) и увеличивайте при необходимости
- Для удаления однотонного студийного фона обычно достаточно допуска 10-20
- Слишком большой допуск может удалить нужные части изображения, если они похожи по цвету на фон
- После применения модификатора проверьте результат на нескольких товарах перед массовой выгрузкой
