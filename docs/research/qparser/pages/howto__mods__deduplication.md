Q-Parser позволяет автоматически удалить дубли товаров по заданной характеристике. Например, удалить товары с одинаковыми артикулами
и оставить только один.

Удаление дублей работает как [фильтр товаров](/howto/mods/filter) и имеет все особенности фильтров.

## Общая информация

Для удаления дублей товаров в меню редактирования товаров выберите "Удалить дубликаты". В появившемся окне необходимо указать
характеристику товаров по которой отсеивать дубли.

При удалении дублей остается первый товар из найденных дублей в стандартном порядке сортировки.

**Обратите внимание**, что удаление дублей осуществляется без учета изменений, внесенных через редактирование товаров и без учета
произвольных сортировок товаров.

![Удаление дублей](/_app/immutable/assets/filter-deduplication.BvnBacjv.png)

## Товары без значения характеристики

Если у товара характеристика пустая или ее нет вовсе, при удалении дублей это считается одним и тем же значением. Поэтому из всех
таких товаров останется только один. Например, при удалении дублей по характеристике "Цвет" из товаров без цвета останется первый,
остальные будут отсеяны как его дубли.

Если товары без значения нужно убрать совсем, добавьте [фильтр](/howto/mods/filter) "Существует" по той же характеристике.
Тогда товары без значения отсеются, а из остальных останется по одному товару на каждое значение. Порядок добавления фильтра и удаления
дублей не важен.
