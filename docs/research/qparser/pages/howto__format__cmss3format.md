Список товаров для CMS.S3 (Megagroup) выгружается в формате CSV. Файл уже подготовлен для импорта на платформу Megagroup,
дополнительных манипуляций не требуется.

Рекомендуем импортировать за один раз файлы не более 500 Кб.

### Список файлов

Выгрузка формирует 4 файла, которые содержат разные данные:

- **categories.csv** — категории;
- **categories-props.csv** — характеристики товаров по категориям;
- **goods.csv** — товары;
- **goods-props.csv** — характеристики товаров;

### 1. В списке товаров нажмите "Выгрузить"

После загрузки товаров на парсер, находясь на странице со списком товаров, нажмите кнопку "Выгрузить".

![Как выгрузить товары в Megagroup - Шаг 1](/static/howto/export-1.png)

### 2. Задайте настройки формата

В появившемся окне выберите формат "CMS.S3 (Megagroup)", задайте необходимые настройки и сформируйте файл для импорта товаров.

### 3. Импортируйте товары в магазин

В разделе редактирования вашего магазина нажмите на ссылку «Импорт», загрузите нужные файлы и запустите импорт.

**Ключевое поле** необходимо выбрать Артикул. **Символ-разделитель** — точка с запятой.

Подробная инструкция доступна по ссылке <https://help.megagroup.ru/import>

## Специальные характеристики

Часть колонок заполняется значением характеристики с фиксированным названием. Если у товара такой характеристики нет, колонка
останется пустой. Эти характеристики не дублируются в дополнительных колонках: туда попадают остальные.

**vendor : Производитель** — характеристика «Бренд».

**weight : Вес** — характеристика «Вес».

**weight\_unit : Единица веса** — характеристика «Единица веса».

**dimensions** — характеристика «Габариты».

**unit : Единица измерения товара** — характеристика «Единица измерения товара».

Название должно совпадать точно. Переименовать характеристику можно в [редактировании товаров](/howto/mods/cols-rename).
