Список товаров на HostCMS выгружается в формате CSV. Файл уже подготовлен для импорта на платформу HostCMS, дополнительных
манипуляций не требуется.

Актуальная инструкция по импорту файла доступна по [ссылке](https://www.hostcms.ru/documentation/modules/shop/exchange/csv/imports/) или вы можете обратиться в поддержку вашего
сайта.

### 1. В списке товаров нажмите "Выгрузить"

После загрузки товаров на парсер, находясь на странице со списком товаров, нажмите кнопку "Выгрузить".

![Как выгрузить товары в HostCMS - Шаг 1](/static/howto/export-1.png)

### 2. Задайте настройки формата

В появившемся окне выберите формат "HostCMS (hostcms.ru)", задайте необходимые настройки и сформируйте файл для импорта товаров.

### 3. Перейдите в раздел импорта товаров на вашем сайте

В панели администратора сайта HostCMS перейдите **Контент → Интернет-магазины**. Выберите нужный магазин, затем кнопку **Товар → Импорт товаров**.

![Как выгрузить товары в HostCMS - Шаг 3](/_app/immutable/assets/export-hostcms-2.DWfdSqt_.jpg)

### 4. Задайте настройки импорта и выберите файл

В появившейся форме необходимо выбрать файл с товарами и задать настройки импорта, которые вам требуются.

Обязательно проверьте соответствие выбранной кодировки кодировке файла.

Если товары содержат фото, скачайте их, распакуйте архив и загрузите куда-нибудь на ваш сервер, чтобы у скрипта импорта был доступ к
этой папке.

В поле **Путь для внешних файлов** укажите путь к папке в которую вы загрузили файлы изображений товаров.

После всех настроек нажмите кнопку **Загрузить**.

![Как выгрузить товары в HostCMS - Шаг 4](/_app/immutable/assets/export-hostcms-3.ChpnaXbt.jpg)

### 5. Проверьте сопоставление полей файла

На следующем шаге проверьте сопоставление полей файла полям вашего магазина. При необходимости создайте нужные поля в магазине.

Если на этом шаге появляется ошибка, скорее всего проблема связана с неверным выбором модификаций или их отсутствием. За помощью
лучше обратиться в поддержку HostCMS.

![Как выгрузить товары в HostCMS - Шаг 5](/_app/immutable/assets/export-hostcms-4.CQ8jFbi-.jpg)

### 6. Дождитесь окончания импорта

На следующем шаге начинается импорт. Он может продлиться какое-то время, зависящее от объема файла.

После завершения импорта появится отчет с информацией о загруженных товарах или возникших ошибках.

![Как выгрузить товары в HostCMS - Шаг 6](/_app/immutable/assets/export-hostcms-5.DbZxfDfW.jpg)

### Ограничения формата

- Поддерживается импорт только одного изображения на товар;
- Выбираемые поля требуют наличия созданной модификации в магазине HostCMS. За подробностями обращайтесь в поддержку HostCMS;

## Специальные характеристики

Часть колонок заполняется значением характеристики с фиксированным названием. Если у товара такой характеристики нет, колонка
останется пустой. Эти характеристики не дублируются в отдельных колонках: туда попадают остальные.

**Название производителя** — характеристика «Бренд».

Название должно совпадать точно. Переименовать характеристику можно в [редактировании товаров](/howto/mods/cols-rename).
