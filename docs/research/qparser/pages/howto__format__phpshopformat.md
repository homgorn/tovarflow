[PHPShop](http://www.phpshop.ru/) — это популярная платформа для создания интернет-магазинов.

### 1. В списке товаров нажмите "Выгрузить"

После загрузки товаров на парсер, находясь на странице со списком товаров, нажмите кнопку "Выгрузить".

![Как выгрузить товары в PHPShop - Шаг 1](/static/howto/export-1.png)

### 2. Задайте настройки формата

В появившемся окне выберите формат "PHPShop", задайте необходимые настройки и сформируйте файл для импорта товаров.

### 3. Импортируйте файл в ваш магазин на PHPShop

В панели управления вашего магазина нажмите **База** - **Импорт данных**, на открывшейся странице задайте необходимые
настройки импорта и нажмите кнопку "Выполнить".

Обратите внимание, что первым необходимо импортировать файл **-categories.csv** для загрузки категорий.

Если при выгрузке вы выбрали скачивание фото товаров в ZIP-архив, то эти фото нужно предварительно загрузить в папку **/UserFiles/Image** и отметить настройку **Полный путь для изображений**.

## Настройки формата

**Разделитель изображений** — позволяет выбрать разделитель для нескольких изображений. Если не выбирать, будет выгружено только
одно изображение на товар.

**ID категорий** — способ формирования ID категорий в файле. Недавно он изменился, поэтому категории, импортированные
раньше, при повторном импорте могут создаться заново. Чтобы сохранить прежние ID, на ограниченное время можно выбрать **Старый метод**.
